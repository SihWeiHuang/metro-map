# Metro Multiverse — Vercel 與 GitHub 重新命名

程式與網站標題已改為 **Metro Multiverse**。  
下面步驟需用瀏覽器登入 **Vercel**、**GitHub**（約 10 分鐘），改完後正式網址會變成 `https://metro-multiverse.vercel.app`。

---

## 一、GitHub 儲存庫改名

1. 打開 https://github.com/SihWeiHuang/metro-map  
2. **Settings**（設定）→ 左側最下方 **General**  
3. **Repository name** 改為：`metro-multiverse`  
4. 按 **Rename**

改名後網址會變成：  
`https://github.com/SihWeiHuang/metro-multiverse`

**本機專案（若 push 失敗時再做）：**

```bash
git remote set-url origin https://github.com/SihWeiHuang/metro-multiverse.git
```

---

## 二、Vercel 專案改名（正式網址）

1. 打開 https://vercel.com/dashboard  
2. 進入目前部署此網站的專案（可能顯示 **metro-map** 或 **metro-map-x01**）  
3. **Settings** → **General**  
4. **Project Name** 改為：`metro-multiverse`  
5. 儲存

新預設網址會是：  
**https://metro-multiverse.vercel.app**

6. **Deployments** → 最新一筆 → **Redeploy**（讓新標題與程式上線）

---

## 三、舊網址導向（建議，避免書籤失效）

若你之前用的是 `https://metro-map-x01.vercel.app`：

1. Vercel 專案 → **Settings** → **Domains**  
2. 確認 **metro-multiverse.vercel.app** 在清單中  
3. 若舊網址 **metro-map-x01.vercel.app** 仍列在 Domains，可保留（Vercel 通常會同時指向同一專案）  
4. **完成 Vercel 改名並確認** `metro-multiverse.vercel.app` **能開啟後**，可在專案根目錄新增 `vercel.json` 讓舊網址自動轉向（選用）：

```json
{
  "redirects": [
    {
      "source": "/:path*",
      "has": [{ "type": "host", "value": "metro-map-x01.vercel.app" }],
      "destination": "https://metro-multiverse.vercel.app/:path*",
      "permanent": true
    }
  ]
}
```

存檔後 commit、push，Vercel 會自動重新部署。

**Mapbox token URL 限制** 請同時包含（見 [上線安全設定.md](上線安全設定.md)）：

```
https://metro-multiverse.vercel.app/*
https://metro-map-x01.vercel.app/*
http://localhost:5173/*
```

過一陣子確認新網址穩定後，可從 Mapbox 移除舊的 `metro-map-x01` 網址。

---

## 四、推送程式讓正式站更新

在本機專案資料夾執行：

```bash
git add -A && git commit -m "Rename brand to Metro Multiverse" && git push
```

若 GitHub 已改名，先執行上一節的 `git remote set-url` 再 push。
