# 底圖樣式調整（Mapbox）

專案使用自訂樣式：`mapbox://styles/ethen9798/cmfceirln001n01sl9bqf4axy`（見 `src/components/MapView.jsx`）。

## 程式已自動處理（無需改 Studio）

`src/map/layers.js` 的 `applyBasemapClutterReduction` 會在載入樣式後：

| 項目 | 行為 |
|------|------|
| Mapbox **Standard**（style 含 `imports`） | 關閉 POI、底圖大眾運輸；**保留** `showRoadLabels`、`showPlaceLabels`；`lightPreset` 見 `src/map/basemapAppearanceConfig.js`（預設 `dusk`，略暗於 `day`） |
| **Classic** 自訂樣式 | 保留路名圖層；隱藏 POI 文字、商店圖示、聚落級地名 |
| 保留文字 | 路名、縣市／行政區、主要 `place-city` / `town` / `district` / `admin` 等 |
| 隱藏文字 | POI、門牌、里鄰／聚落級地名（如石牌、唭哩岸等，避免與站名搶位） |
| 站名圖層 | 智慧閃避程度 **55**（`stationLabelCollision.js`）：站名 `symbol-sort-key` 高於底圖；**縣市／行政區等主要地名**設為可選、低優先，重疊時可被擠掉；拖曳時暫停閃避 |

若仍覺得亂，多半是 **Studio 裡的圖層** 或 **Standard 不支援程式改動的圖層**，需手動調整下列項目。

---

## 你必須在 Mapbox Studio 調整的部分

登入 [Mapbox Studio](https://studio.mapbox.com/) → 開啟樣式 **ethen9798 / …** → 依需求修改後 **Publish**。

### 1. 先確認樣式類型

- **Mapbox Standard**（有 Basemap import / 3D 建物）  
  - 細部開關在 **Imports → basemap → Config**（與程式內 `showRoadLabels` 等對應）。  
  - Studio 裡可設預設：關 POI、**開路名**、保留 Place labels（聚落級建議關）。  
- **Classic**（傳統圖層列表）  
  - 需逐層調 **Visibility**、**Min zoom**、**Filter**；程式隱藏改不到的圖層時以 Studio 為準。

### 2. 建議在 Studio 關閉或延後顯示

| 類別 | 建議 |
|------|------|
| POI（商店、餐廳、景點圖示＋文字） | 關閉或只留 `transit` |
| 道路標籤 / 路盾 | 路名可保留；路盾圖示若太花可關或提高 min zoom |
| 門牌、巷弄、水道名 | 關閉 |
| 3D 建物 | 可關或降低對比（減視覺雜訊） |

### 3. 建議保留

| 類別 | 建議 |
|------|------|
| 縣市、區、主要地名 | 保留 |
| 水域、公園填色（無文字） | 可保留作背景 |
| 道路名稱 | 保留 |
| 捷運／鐵路「線條」 | 可保留淡色；**文字**可關（本專案自繪路網） |

### 4. 發佈與快取

- 修改後按 **Publish**，正式環境才會更新。  
- 本機 `npm run dev` 有時需硬重新整理才看到新樣式。

### 5. 無法只靠程式達成的效果

- 調整**配色、字體、道路粗細、背景飽和度**  
- Standard **lightPreset**（日夜）、**font** 列表  
- 新增/刪除**整組資料來源**（例如完全不要商業 POI 圖層）  
- 圖層在 import 內且 GL JS 回傳錯誤時的**個別圖層**微調

## 相關程式位置

| 檔案 | 說明 |
|------|------|
| `src/components/MapView.jsx` | 樣式 URL、`applyBasemapClutterReduction` 呼叫時機 |
| `src/map/layers.js` | 底圖減雜訊規則、`ensureMetroLayerStackOrder` |
| `src/map/stationLabelCollision.js` | 站名閃避程度 0–100、`STATION_LABEL_COLLISION_LEVEL`（預設 55） |
| `src/map/basemapAppearanceConfig.js` | 底圖明暗：`MAPBOX_BASEMAP_LIGHT_PRESET`（`day` / `dawn` / `dusk` / `night`） |

若要改「保留哪些地名」規則，編輯 `layers.js` 內 `CORE_PLACE_LABEL_RE`、`CLUTTER_BASEMAP_LABEL_RE`。
