# 短網址分享 — Vercel KV 設定

分享連結功能需要 **Redis（KV）** 儲存上傳的路線 JSON。Vercel 已將舊版「Vercel KV」整合至 **Marketplace 的 Redis（Upstash）**。

## 一、在 Vercel 建立 Redis

1. 登入 [Vercel Dashboard](https://vercel.com/) → 選擇 **Metro Multiverse** 專案  
2. 上方 **Storage** 或 **Integrations** → **Browse Marketplace** → 搜尋 **Redis** / **Upstash**  
3. 建立資料庫並 **Connect to Project**（勾選 Production、Preview）  
4. 連結後會自動寫入環境變數，通常包含：  
   - `KV_REST_API_URL`  
   - `KV_REST_API_TOKEN`  

無需手動把 token 寫進 GitHub；僅存在 Vercel 專案環境變數即可。

## 二、重新部署

新增整合後請 **Redeploy** 一次正式站，API `/api/share` 才會讀得到 KV。

## 三、驗證

1. 在地圖上畫至少一條使用者路線  
2. 開啟 **路線檔案** → **分享連結** → **產生連結**  
3. 複製 `https://你的網域/r/xxxxxxxx` 用無痕視窗開啟，應進入分享檢視模式  

若出現「分享功能尚未設定完成」，代表 KV 環境變數未注入或部署在舊版 build。

## 四、本機開發

### A. 只預覽「檢視模式」畫面（push 前看 UI，最簡單）

1. 執行 `npm run dev`  
2. 瀏覽器開啟（把 `{id}` 換成正式站分享網址裡的那段，例如 `29MzZnsu`）：

   **http://localhost:5173/r/{id}**

3. 本機會載入**你電腦上最新程式**的檢視模式 UI，並透過 proxy 向正式站讀取該分享的路線資料。

> 注意：網址要用 `localhost:5173/r/...`，不要直接開 `https://metro-multiverse.vercel.app/r/...`（那是正式站舊版 UI）。

「產生分享連結」在本機仍可能失敗（POST 也會 proxy 到正式站）；**檢視已存在的連結**用此法即可。

### B. 完整測試建立＋讀取 API

`npm run dev` **不會**在本機跑 Vercel Serverless。要測「產生連結」等完整流程請：

```bash
npx vercel login
npx vercel link
npx vercel env pull .env.local
npx vercel dev
```

並在 Vercel 專案連結 Redis 後，用 CLI 拉取環境變數。

## 五、目前限制（程式內建）

| 項目 | 數值 |
|------|------|
| 分享連結有效天數 | 30 天 |
| 單次分享 JSON 上限 | 200 KB |
| 每 IP 每日建立連結次數 | 20 次 |
| 全站使用者路線（路線層級）上限 | 50 條 |

常數定義於 `shared/shareLimits.js`。
