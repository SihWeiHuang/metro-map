這份文件配合「免費上線、防止 Mapbox 帳單爆掉」使用。  
**程式與 GitHub 部分已替你檢查過**；Mapbox / Vercel 後台需用瀏覽器登入，約 15～20 分鐘。

正式站（重新命名 Vercel 後）：**https://metro-multiverse.vercel.app**  
若尚未改名，可能仍是 https://metro-map-x01.vercel.app — 見 [部署與重新命名.md](部署與重新命名.md)

## 二、請你親自完成：Mapbox（約 10 分鐘）

登入：https://account.mapbox.com/

### 步驟 1：建立「可設網址限制」的新 token（重要）

畫面上的 **Default public token** 旁邊 URLs 是 **N/A**，代表**這組不能加 URL 限制**（Mapbox 官方設計如此）。

請改做下面流程：

1. 在 **Access tokens** 頁面，點左上藍色按鈕 **「+ Create a token」**（建立權杖）
2. **Token name** 填：`Metro Multiverse 正式站`
3. 往下捲，找到 **URL restrictions**（或 **Allowed URLs**）
4. 在允許清單加入（一行一個；**不可使用 `*`**，Mapbox 會拒絕）：

```
https://metro-multiverse.vercel.app
http://localhost:5173
http://localhost:4173
```

（只填網域＋通訊協定即可，不必加 `/*` 或結尾 `/`。）

5. 若畫面有 **Public scopes**，維持預設即可
6. 按 **Create token** → **立刻複製**新 token（`pk.` 開頭）

### 步驟 1b：把新 token 貼到 Vercel

1. 打開 https://vercel.com → 專案 **metro-multiverse**（或尚未改名前的專案）
2. **Settings** → **Environment Variables**
3. 編輯 `VITE_MAPBOX_TOKEN` → 貼上新 token → Save
4. **Deployments** → **Redeploy**

---

### 步驟 2：每月預算上限 + Email 警報

1. **Settings** → **Billing**
2. 設 **Budget cap** / **Spend limit**
3. 開啟 **Email notifications**

---

### 步驟 3：每週看一眼用量

**Statistics** / **Usage** — 若異常飆高，檢查是否被刷流量。

---

## 三、Vercel 快速確認（約 3 分鐘）

2. **Redeploy** 後開正式站，地圖能拖動即成功
